Instal·lació i ajuda

Al portàtil, mòbil i tauleta

Chrome o Edge: utilitza «Instal·lar» quan el navegador ho permeti, o l’opció d’instal·lació del menú.

iPhone / iPad: obre la web a Safari, toca Compartir i «Afegir a la pantalla d’inici». Activa «Obrir com a app web» quan aparegui.

Mac amb Safari compatible: utilitza l’opció d’afegir al Dock. Si el navegador no ofereix instal·lació, continua utilitzant la web o obre-la amb un navegador compatible.

Cal obrir la web publicada amb HTTPS. Un fitxer obert amb doble clic (file://) no permet instal·lar aquesta PWA.

Sense connexió i actualitzacions

Obre l’app amb internet i espera el missatge «Disponible sense connexió». Les pantalles, els exemples i els càlculs locals quedaran desats al navegador. Els enllaços externs continuen necessitant internet.

El navegador pot eliminar les dades locals si es neteja l’emmagatzematge. La còpia de seguretat desa les marques PAU, el tema i els darrers valors introduïts. No sincronitza dispositius.

Abast d’aquesta conversió

S’han conservat els temes, les fórmules i els 15 exemples de l’HTML aportat. El quadre PAU és manual: no és una nova comparativa oficial dels exàmens.

Les derivades utilitzen un motor simbòlic elemental. Els zeros, les àrees i els punts candidats utilitzen mètodes numèrics. No s’accepten integrals impròpies; no es demostra el domini, l’existència de límits ni tots els extrems a partir del mostreig. No és un sistema algebraic universal ni una revisió completa del contingut docent.
