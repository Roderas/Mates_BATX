# Procedència i referències

## Materials de partida

HTML aportat: `mates-docent(1).html`. Base de conversió prèvia: `mates_docent_pwa_instalable_github.zip`. La guia d’aquesta base es conserva separada del nou resolutor. No s’ha substituït la guia per un suposat programa oficial diferent.

## Referència externa de funcionament

Symbolab en castellà, consultat l’1 d’octubre de 2026: https://es.symbolab.com/
S’ha pres com a referència el flux entrada/solució/passos/gràfica/quadern. No s’ha reutilitzat el seu motor, logotip, textos didàctics o compte d’usuari. Aquesta aplicació no està afiliada a Symbolab.

## Documentació tècnica

MDN, Making PWAs installable: https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable
GitHub, Configuring a publishing source for your GitHub Pages site: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Les indicacions de desplegament i instal·lació es basen en aquesta documentació. La instal·lació sobre un compte GitHub i dispositius físics no s’ha executat en aquest lliurament.

## Codi i dependències

El nou motor i la interfície s’han implementat per a aquest projecte. No s’han incorporat biblioteques CAS ni fonts remotes. Les eines Python/Node/Playwright són eines de construcció i verificació, no dependències per obrir l’app publicada.
